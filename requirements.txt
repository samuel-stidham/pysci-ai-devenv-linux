# pysci-ai base environment: top-level packages only.
#
# pip resolves the transitive dependency tree from these. Do not pin the
# ~500 transitive deps by hand. Native system libraries (hdf5, geos, SDL2,
# CUDA, ...) come from devenv.nix, not from here.
#
# ── PyTorch / CUDA ───────────────────────────────────────────────────
# The RTX 5090 is Blackwell (compute capability sm_120). Blackwell support
# first shipped in CUDA 12.8, so the cu126 wheels the PyTorch site defaults
# to do NOT contain sm_120 kernels. We use the CUDA 13.0 index instead,
# which is well past 12.8 and matches the host's 595-series driver.
#
# This is --extra-index-url, not --index-url, on purpose: torch and friends
# come from the PyTorch index, every other package below still comes from
# PyPI. Using --index-url would point pip at the PyTorch index for the whole
# file and most of these packages would not be found.
--extra-index-url https://download.pytorch.org/whl/cu130
